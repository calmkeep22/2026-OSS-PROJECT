# ai-insight-http

`ai-insight-api` 의 HTTP 구현. 파이썬 분석 서비스(`ai-service`)를 부릅니다.

## 공개 API

| 타입 | 하는 일 |
|---|---|
| `HttpAiInsightAdapter` | `AiInsightPort` 구현. `/brief` · `/predict` · `/similar` · `/health` |
| `HttpNewsAdapter` | `NewsPort` 구현. `/news` · `/chat` · `/news/track` |

둘 다 생성자에 서비스 주소를 받습니다. 조립은 `DesktopServices` 가 합니다.

## 의존성

`ai-insight-api`, `finance-domain`, Jackson, JDK HTTP 클라이언트.

화면과 증권사 어댑터는 보지 않습니다.

## 이 모듈이 지키는 것

**봉을 우리가 보냅니다.** 서비스가 스스로 조회하게 두면 증권사 시세와 다른 값을 쓰게 되어,
사용자가 화면에서 보는 차트와 분석 근거가 어긋납니다.

**장중 미완성 봉을 뺍니다.** `TradingSessionBars` 가 마감 20분 전까지의 오늘 봉을 걸러
냅니다. 그대로 넣으면 "내일을 맞힌다" 가 "이미 본 값을 되읽는다" 가 됩니다.

**판정과 같은 쪽 확률을 고릅니다.** 확률 필드 이름이 타깃에 따라 바뀌는데 아무거나 집으면
"하락" 판정에 상승확률 49.3퍼센트가 붙습니다. 판정에 맞는 쪽이 없으면 그 예측을 통째로
접습니다 — 반대쪽 숫자를 보여 주는 것은 아무것도 안 보여 주는 것보다 나쁩니다.

**부분 실패를 전체 실패로 만들지 않습니다.** 방향 예측이나 닮은 차트를 못 받아도 변동성과
이상감지는 그대로 줍니다.

**본문을 Jackson 으로 만듭니다.** 사용자가 친 질문이 그대로 들어가는 자리라 따옴표나
줄바꿈 하나에 본문이 깨집니다. 서버는 "본문을 읽지 못했습니다" 로만 답해 원인을 찾기
어렵습니다.

**기사 시각을 못 읽으면 지금으로 채우지 않습니다.** 오래된 기사가 방금 것으로 보이면
사용자는 그것을 새 소식으로 읽습니다.

## 시간 제한

| 호출 | 제한 | 이유 |
|---|---|---|
| 분석 · 예측 · 유사도 | 15초 | 실측 167ms. 넘으면 서버가 준비 중이거나 막힌 것 |
| 뉴스 · 질의응답 | 90초 | RSS 를 거쳐 처음 한 번이 실측 11~58초 |

서비스가 결과를 10분 들고 있으므로 오래 기다리는 것은 그 종목을 처음 여는 한 번뿐입니다.

## 비목표

- 서버를 띄우지 않습니다. `AiServiceProcess`(앱 쪽)가 합니다.
- 결과를 저장하지 않습니다. 보관은 서비스 쪽 `news_cache` 가 합니다.
- 응답 문장을 고쳐 쓰지 않습니다. 서비스가 스크린리더용으로 쓴 것을 그대로 옮깁니다.
