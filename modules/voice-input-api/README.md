# voice-input-api

음성 명령 계약. 값과 포트와 규칙만 있고 인식기는 없습니다.

## 공개 API

| 타입 | 하는 일 |
|---|---|
| `VoiceInputPort` | 한마디를 듣고 글로 받아 옵니다 |
| `AudioCapturePort` | 마이크에서 소리를 받아 옵니다 |
| `Transcript` | 알아들은 말과 확신도. 인식기가 낸 그대로입니다 |
| `RecognitionMode` | 정해진 명령어만 알아듣는지, 자유 발화가 되는지, 못 쓰는지 |
| `VoiceCommandParser` | 알아들은 말을 명령으로 바꿉니다 |
| `VoiceCommand` | 무엇을 시켰는지. 되읽어 줄 문장을 스스로 만듭니다 |
| `Intent` | 시킬 수 있는 일 21가지. 확인이 필요한지 스스로 압니다 |
| `KnownStock` | 말로 부를 수 있는 종목. 영문 이름의 한글 읽기를 스스로 붙입니다 |
| `KoreanNumbers` | "열 주" · "십 주" · "10주" 를 같은 수로 읽습니다 |

## 의존성

`finance-domain` 만 봅니다. 종목명을 한글로 어떻게 읽는지(`KoreanReading`)는 음성의
규칙이 아니라 도메인의 규칙이라 그쪽에 있습니다. 검색창에 쳐도 말로 해도 같은 방식으로
맞아야 하기 때문입니다.

JavaFX, Java Sound, HTTP 클라이언트를 import 하지 않습니다. `verifyModuleBoundaries`
가 막습니다. 인식기를 갈아 끼워도 이 모듈은 바뀌지 않습니다.

## 이 모듈이 지키는 것

**되돌릴 수 없는 일은 만들어 주지 않습니다.** 종목이나 수량이 빠진 매수·매도는 명령이
되지 않고 `UNKNOWN` 이 됩니다. 빠진 값을 채워 넣으면 사용자가 말하지 않은 주문이
나갑니다. `VoiceCommand.readyToRun()` 은 주문에 대해 언제나 거짓입니다 — 아무리
또렷하게 알아들었어도 사람이 한 번 더 확인해야 합니다.

**붙이는 기준이 명령마다 다릅니다.** 화면 이동은 헐겁게 붙입니다. 잘못 붙어도 화면만
바뀌고 되돌리면 그만입니다. 매수·매도·종목명은 빡빡하게 붙입니다 — "매수" 와 "매도" 는
한 글자 차이라, 헐겁게 붙이면 팔라는 말이 사라는 말이 됩니다.

**모르면 모른다고 합니다.** 비슷한 것을 억지로 고르지 않고, 들은 말을 그대로 담아
돌려줍니다. `VoiceCommand.heard` 가 항상 살아 있는 이유입니다. 무엇으로 들렸는지
알려 주지 않으면 사용자는 자기 발음을 탓하게 됩니다.

**종목을 놓쳤으면 되묻습니다.** 현재가·뉴스·닮은차트처럼 어느 종목인지 알아야 답할 수
있는 명령은, 종목을 못 붙였을 때 화면에 떠 있던 다른 종목으로 대신 답하지 않습니다.
사용자는 자기가 말한 종목의 답을 들었다고 믿게 되고, 화면을 볼 수 없으면 틀렸다는 것을
알 방법이 없습니다.

## 정확도를 인식기에만 맡기지 않습니다

인식기를 무엇으로 바꿔도 한국어 종목명은 틀립니다. 실측에서 whisper 는 "관심종목" 을
"관심 좀 목" 으로, "청각 차트" 를 "청각착도" 로 적었습니다.

인식기는 종목 목록을 모르고 파서는 압니다. 그래서 편집 거리로 가장 가까운 것을 고릅니다.
그 차이가 모델 두 단계 값어치를 해서, 느린 기계에서도 쓸 수 있습니다.

`MeasuredWhisperOutputTest` 가 실제로 돌려 나온 출력을 그대로 담고 있습니다. 지어낸
오인식으로 검사하면 실제로 나오지 않는 오류만 막고 실제로 나오는 오류는 놓칩니다.

## 쓰는 법

```java
var known = List.of(new KnownStock("005930", "삼성전자"),
                    new KnownStock("035420", "NAVER"));
var parser = new VoiceCommandParser(known);

VoiceCommand command = parser.parse("네이버 현재가 알려줘");
// intent=QUOTE, stock=NAVER   ("네이버" 를 영문 등록명에 붙입니다)

if (command.readyToRun()) run(command);
else ask(command.confirmationQuestion());
```

인식기에 미리 알려 줄 말은 두 가지로 냅니다. `vocabularyTerms()` 는 자유 발화 인식기의
프롬프트에 물릴 **낱말**이고, `grammarPhrases()` 는 정해진 문장만 알아듣는 인식기에
등록할 **문장**입니다. 자유 발화 인식기에 문장을 물리면 소리가 불분명할 때 그 문장을
통째로 되뱉습니다.

## 비목표

- 소리를 다루지 않습니다. 마이크는 `voice-input-java-sound` 에 있습니다.
- 인식하지 않습니다. 인식기는 포트 뒤에 있습니다.
- 화면을 모릅니다. `Intent` 는 무엇을 하려는지까지만 담고, 어느 화면으로 갈지는 앱이 정합니다.
