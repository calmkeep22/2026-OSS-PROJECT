# OpenStock Access 접근성 수동 검증 체크리스트

자동 검사는 접근 가능한 이름과 ViewModel 정책을 확인한다. 실제 스크린리더의 읽기 순서와 음성 품질은 아래 절차로 별도 확인한다.

## NVDA + Windows

1. NVDA를 실행하고 앱을 `gradlew.bat :apps:desktop-javafx:run`으로 시작한다.
2. `Tab`과 `Shift+Tab`만 사용해 상단 검색, 사이드바, 본문, 상태 표시줄로 이동한다.
3. 사이드바 상위 메뉴를 `Enter` 또는 `Space`로 열고 닫으며 `펼쳐짐`·`접힘` 상태가 읽히는지 확인한다.
4. 사이드바 상위 메뉴에서 `오른쪽 방향키`로 메뉴를 열거나 첫 하위 메뉴로 이동하고, 하위 메뉴에서 `왼쪽 방향키`로 상위 메뉴에 복귀하는지 확인한다.
5. 각 버튼에서 동작과 대상이 함께 읽히는지 확인한다.
6. 표에서 방향키로 행과 열을 이동하며 헤더·종목·값이 구분되어 읽히는지 확인한다.
7. 종목 상세의 `접근 가능한 표` 탭에서 차트와 동일한 OHLCV가 읽히는지 확인한다.
8. 매수·매도·정정·취소 확인 창에서 환경, 계좌, 종목, 가격, 수량, 총액이 모두 읽히는지 확인한다.
9. 고대비와 큰 글자를 켠 뒤 포커스 테두리와 화면 잘림을 확인한다.
10. TTS를 끈 상태에서도 모든 정보와 오류가 화면 텍스트로 남는지 확인한다.

## 필수 키보드 경로

- `Alt+D`: 홈
- `Alt+S`: 통합 검색
- `Alt+O`: 주문
- `Alt+A`: 계좌
- `Alt+R`: 청각 차트
- `Ctrl+,`: 설정
- 관심종목: `Enter`, `Delete`, `Ctrl+위/아래`

## 실패 기록

문제가 발견되면 화면, 컨트롤, 입력 키, NVDA가 읽은 문장, 기대 문장을 함께 이슈에 기록한다.
